# ZeroImageStudio

ZeroImageStudio — открытая нода ComfyUI. Она разворачивает редактор на весь браузер: область на холсте, генерация или правка внутри неё, результат отдельным слоем. Свёрнутая нода отдаёт в граф сведённый кадр (`IMAGE`), маску (`MASK`) и JSON слоёв (`LAYERS`).

Два пайплайна, и ни один не привязан к одному чекпоинту:

- **Создание** — один общий граф: чекпоинт или diffusion-модель с текстовым энкодером и VAE, LoRA и сэмплер. Тот же код делает text-to-image, img2img и inpaint.
- **Редактирование** — фото на холсте, правка промтом и бесшовная вклейка на новый слой. Krea 2 Edit встроен в пакет. Qwen Image 2.1 — та же модель, что и для создания, но в этом режиме через `TextEncodeQwenImage21` и референсы.

## Установка

Нужен ComfyUI, в котором уже есть Krea 2 и Qwen Image 2.1. Qwen Image 2.1 появился в ComfyUI 0.37; пакет проверялся на 0.42.

Корень этого репозитория и есть папка ноды. Клонирование сразу в `custom_nodes` достаточно:

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/zeroleloushe/ZeroImageStudio.git
```

Перезапустите ComfyUI. В графе добавьте ноду **ZeroImageStudio — редактор изображений** и нажмите **Развернуть ZeroImageStudio**. Esc или **Свернуть в ноду** записывает кадр в выходы ноды.

Редактор открывается со страницы расширения `/extensions/ZeroImageStudio/`. Имя папки после `git clone` менять не нужно.

Нода **ZeroImageStudio — загрузчик моделей** необязательна. Редактор сам читает папки моделей ComfyUI и ставит отдельный промт в очередь. Загрузчик нужен, только если в графе должны быть сокеты `MODEL`, `CLIP` и `VAE`.

## Что нужно

Отдельных pip-зависимостей нет. Хватает того, что уже ставится с ComfyUI: `torch`, `numpy`, `Pillow`, `einops`, `aiohttp`.

Веса в репозиторий не входят. Положите файлы в обычные папки ComfyUI и выберите их в редакторе. Записи в `hints/models.json` только подсказывают типичные имена:

| Подсказка | Файлы |
| --- | --- |
| Krea 2 | `krea2_turbo_fp8_scaled.safetensors`, CLIP `qwen3vl_4b_fp8_scaled.safetensors` типа `krea2`, VAE `qwen_image_vae.safetensors` |
| Krea 2 Edit V2 | то же плюс одна LoRA режима в `models/loras/`: [krea2_general_edit_v2.safetensors](https://huggingface.co/conradlocke/krea2-identity-edit/blob/main/krea2_general_edit_v2.safetensors) (Правка) или [krea2_identity_edit_v2.safetensors](https://huggingface.co/conradlocke/krea2-identity-edit/blob/main/krea2_identity_edit_v2.safetensors) (Персонаж по референсу). База — [Comfy-Org/Krea-2](https://huggingface.co/Comfy-Org/Krea-2) |
| Qwen Image 2.1 | UNET Qwen Image 2.1, CLIP типа `qwen_image` и подходящий VAE. Одна запись и в Создании, и в Редактировании |

Ключ Civitai и OpenAI-совместимый LLM (Ollama, llama.cpp, LM Studio) необязательны. Оба пишутся в каталог пользователя ComfyUI (`user/zeroimagestudio/settings.json`), не в этот репозиторий. Пока поля пустые, кнопки сообщают, что сервис не настроен.

## Как собирается генерация

Создание и обычный inpaint используют только ноды ядра: `CheckpointLoaderSimple` либо `UNETLoader` + `CLIPLoader` + `VAELoader`, затем `LoraLoader`, `CLIPTextEncode`, пустой латент или VAE-кодирование, `KSampler`, `VAEDecode`, `SaveImage`. Qwen Image 2.1 в Создании без картинки тоже идёт этим путём: `CLIPTextEncode` и `EmptySD3LatentImage` запрошенного размера.

Способы редактирования:

| Способ | Граф |
| --- | --- |
| Inpaint / img2img | Тот же, что и Создание. С маской — `VAEEncodeForInpaint` или `InpaintModelConditioning`. Без маски кроп идёт в img2img; если denoise оставлен равным 1, подставляется 0.75. |
| Krea 2 Edit | `ZeroImageStudioKrea2EditModelPatch` и `ZeroImageStudioKrea2EditGroundedEncode`. |
| Qwen Image 2.1 | Редактирование: `TextEncodeQwenImage21`, слоты `images.image_1` … `images.image_16`. Создание без картинки: `CLIPTextEncode` и `EmptySD3LatentImage`. |
| Прежний Qwen Image Edit | Ядро: `TextEncodeQwenImageEdit`. Это не 2.1. |

Вклейка на NumPy: растушёвка, жёсткая маска или Пуассон (Якоби по пирамиде) и по желанию подгон цвета по рамке маски (Reinhard). Исходный слой остаётся снизу.

## Krea 2 Edit

Прямой проход правки взят из [lbouaraba/comfyui-krea2edit](https://github.com/lbouaraba/comfyui-krea2edit) v2.0.0 (коммит `13ef60f`, Apache-2.0). Подробности — в [README автора](https://github.com/lbouaraba/comfyui-krea2edit/blob/v2.0.0/README.md), примере [workflow](https://github.com/lbouaraba/comfyui-krea2edit/blob/v2.0.0/workflows/krea2_identity_edit.json) и в `NOTICE`.

Что делают две ноды:

1. **Патч модели.** VAE-латент исходника и одного необязательного второго референса ставится в `SingleStreamDiT` как кадры RoPE 1 и 2. Режим `fit` пересчитывает картинку в пикселях на сетку выхода. Подключите VAE, исходное изображение и тот же латент, что идёт в сэмплер, чтобы кодирование прошло до сэмплинга.
2. **Grounded encode.** Инструкция токенизируется вместе с картинкой шаблоном Qwen3-VL (`<|vision_start|><|image_pad|><|vision_end|>` и текст). При CFG выше 1 негатив тоже заземляется на ту же картинку с пустым промтом. `grounding_px` ограничивает длинную сторону для визуального энкодера (по умолчанию 768; для лиц часто ставят 1024).

Нужны обе ноды. Обычный `CLIPTextEncode` не совпадает с тем, как учили LoRA.

В примере workflow у автора: 1024×1024, euler / simple, CFG 1, 10 шагов, grounding 768. В его README быстрый путь Turbo — около 8 шагов при CFG 1, а для удаления объекта — модель Raw, CFG около 3 и порядка 20 шагов. В этом редакторе denoise для Krea принудительно 1: локальность даёт маска.

У записи **Krea 2 Edit V2** два режима, и каждый сам ставит свою LoRA в стек на силе 1.0. Эта строка системная: её нельзя выключить, сменить силу или удалить. Свои LoRA остаются сверху.

| Режим | LoRA | Кадры | Позиция | Grounding |
| --- | --- | --- | --- | --- |
| Правка | `krea2_general_edit_v2.safetensors` | холст, без дополнительного референса | aligned | 768 |
| Персонаж по референсу | `krea2_identity_edit_v2.safetensors` | холст — сцена, первый референс — человек; если сцены нет, референс — единственный кадр | beside, справа от кадра, когда сцена есть | 1024 |

В панели «Референсы» одна строка говорит, какой слот сцена, а какой человек. Выше 2 Мп редактор и граф предупреждают: исходник может протекать, объект — двоиться. Для удаления объекта подсказка предлагает модель Raw, CFG около 3 и около 20 шагов.

Панель «Модель» предупреждает только об одной вещи: нет LoRA выбранного режима Krea 2 Edit V2. Строка показывает имя файла, папку `models/loras/`, ссылку «Скачать» и **Проверить снова**. UNET, CLIP и VAE так не проверяются: подойдут другие версии и свои файлы. Пустой слот остаётся «— выбрать —», рядом нейтральная подсказка с типичными именами. **Сгенерировать** в этом случае пишет коротко «Выберите UNET» (или CLIP, VAE, чекпоинт) и не предлагает скачивание. Уже выбранный файл редактор не подменяет рекомендованным.

Список рекомендованных файлов — в **Настройки → Модели и загрузки**: Krea 2, обе LoRA Krea 2 Edit V2 и Qwen Image 2.1. У каждой строки имя, папка, «установлен» или «не установлен» и ссылка на официальную страницу. Это справка, не ошибка.

В **Параметрах графа** тот же пайплайн можно направить на установленный пакет `comfyui-krea2edit` вместо встроенных нод.

## Qwen Image 2.1

В Создании без исходного изображения промт кодирует `CLIPTextEncode`, а кадр задаёт `EmptySD3LatentImage` ровно запрошенной ширины и высоты, кратно 16. Холст 832×1216 даёт латент 832×1216, в том числе неквадратный. Ядро ComfyUI при сэмплинге дополняет пустой 16-канальный латент до формата модели (у Qwen Image 2.1 это 64 канала и сжатие 16).

В Редактировании и при img2img с картинкой размер берёт `TextEncodeQwenImage21` по референсу (`resolution` 0 сохраняет размер кропа, кратно 32). Сэмплировать другой размер нельзя: правка съезжает. При `resolution` 1024 и подключённом VAE у ComfyUI известен шум на референсах ([issue #16435](https://github.com/Comfy-Org/ComfyUI/issues/16435)). Редактор предупреждает и предлагает 992 или 1056. В промте картинки называются `<image1>`, `<image2>` и далее. Референсов передаётся до 16.

## Как править фото

1. Загрузите снимок: **Открыть изображение**, перетаскивание на холст или Ctrl+V. Если у ноды в графе подключён вход `IMAGE` (обычно Load Image с выбранным файлом), то же окно открывается при развороте редактора.
2. Перед размещением открывается импорт: кадрирование, предел в мегапикселях (только уменьшение, кратно 16) и выбор «как новый холст» или «слоем». Исходный файл на диске не переписывается.
3. Область по умолчанию — весь холст. Разрешение генерации тогда совпадает с холстом и округляется до кратного 16 (холст 832×1216 даёт 832×1216). То же число стоит в подписи на холсте, в строке инструмента и в инспекторе: `832×1216 · 1.01 МП`. Свою область ставят инструментом G или кнопкой «Весь холст» в шапке инспектора. Аспект и мегапиксели — два списка одной ширины. Поле «Своё» появляется только когда выбран этот пункт. То же окно выбора размера — у «Размер холста».
4. Напишите промт правки и нажмите **Сгенерировать**. Результат бесшовно ложится на новый слой «Правка N» поверх исходника. Исходный слой не меняется. Каждая следующая правка добавляет свой слой.

Область и маска поверх загруженного кадра.

Две правки подряд: «Правка 2» и «Правка 1» лежат над исходным слоем, его пиксели не меняются.

## Редактор

- Новый проект открывается пустым холстом 1024×1024 с видимой рамкой, без карточки-заглушки. «Открыть изображение» — кнопка в шапке холста. Перетаскивание и Ctrl+V тоже открывают импорт, без оверлея. Размер пустого холста меняется через «Размер холста». Демо-портрет и примеры галереи только с `?demo=1`.
- Масштаб вмещается в окно при загрузке, смене размера окна и холста. В шапке холста: вместить, 100%, плюс и минус, процент. Колёсико крутит вокруг курсора, пробел двигает кадр, Ctrl+0 вмещает, Ctrl+1 — 100%.
- Параметры инструмента (кисть, маска, область) стоят полосой под шапкой холста, не поверх картинки.
- Перемещение, рамка, лассо, масштаб, кадрирование, кисть, ластик, пипетка, маска, область генерации, рука, зум. Буквы инструментов — в подсказках, шпаргалка на `?`. `[` и `]` меняют размер кисти. Ctrl+S сохраняет, Ctrl+Z и Ctrl+Shift+Z — отмена и повтор, в том числе слоёв и генераций.
- Сид по умолчанию случайный: каждый запуск берёт новый, он пишется в метаданные слоя и галереи. Кубик ставит новый сид, режимы «фиксированный» и «+1» рядом.
- **Сгенерировать** не нажимается, пока нет промта, выбранного UNET, CLIP и VAE (или чекпоинта), LoRA режима Krea 2 Edit или (в правке) картинки. Пустой слот называется коротко: «Выберите UNET». Другое имя файла ошибкой не считается. Предупреждение со ссылкой «Скачать» есть только у LoRA режима.
- Пока идёт счёт, на области видны шаг и превью, кнопка становится **Отмена**.
- Несохранённый проект предупреждает при сворачивании и при закрытии вкладки. Автосохранение — раз в 3 минуты в `user/zeroimagestudio`.
- Список моделей зависит от режима. В **Создании** — Krea 2 и Qwen Image 2.1. В **Редактировании** — Krea 2 Edit V2 и Qwen Image 2.1. У Krea 2 Edit V2 переключатель **Правка** / **Персонаж** (полное имя «Персонаж по референсу» — в подсказке). У каждой подсказки в `hints/models.json` есть `pipelines`. Переключение режима помнит выбранную модель отдельно.
- Референсы видны в обоих режимах. В Создании они не попадают в граф диффузии и служат только картинками для LLM («Описать изображение», «Улучшить»). В Редактировании Qwen Image 2.1 берёт до 16, в промте `<image1>`…. Krea в режиме «Правка» отправляет только холст. «Персонаж по референсу» берёт холст как сцену и первый референс как человека; без сцены этот референс — единственный кадр. Клик по карточке выбирает кадр для LLM.
- Панель «Промт» по умолчанию компактная: поле на две строки, пока печатаешь растёт до четырёх и дальше прокручивается, **Сгенерировать** стоит справа той же высоты (Ctrl+Enter в подсказке кнопки). Шеврон рядом открывает полный вид: негатив, пресеты, LLM. Обратно — та же кнопка, подсказка «Свернуть промт». В компактном виде активные пресеты — одна тонкая строка, или ничего. Выбор пишется в этом браузере (`zeroimagestudio.promptMode`) и не связан с цветной точкой, которая сворачивает панель до шапки. Освободившееся место забирает холст.
- Пресеты промта в полном виде открываются кнопкой **Пресеты промта**: поиск, категории, включение, ДО/ПОСЛЕ, порядок. Они хранятся в `user/zeroimagestudio/prompt_presets.json`.
- В режиме **Создание** кадр на весь холст заменяет изображение (один слой «Холст»). Предыдущий результат остаётся в галерее и в отмене. Область и режим **Редактирование** по-прежнему кладут каждый результат на новый слой, исходник не трогается.
- Инспектор называется просто «Инспектор». Цветная точка в шапке и есть сворачивание. Справа — контекст («весь холст», «область» или имя слоя) и кнопка «Весь холст». Сетка: X/Y и W/H, затем аспект со сменой ориентации и мегапиксели одной ширины, одна строка результата. Число мегапикселей вводится только в пункте «Своё». Вклейка (Poisson, шов, контекст, цветовой подгон) свёрнута. Внизу одна строка: «Весь холст → новая картинка» или «→ новый слой».
- Боковые панели и промт сворачиваются цветной точкой в шапке (или двойным щелчком по заголовку) до одной полосы. Их можно перетаскивать за шапку между левой и правой колонками и вокруг промта. Холст остаётся по центру. Меню **Вид** прячет панель целиком. Раскладка пишется в браузер и в `settings.json`. «Сбросить раскладку» — в меню **Вид** и в настройках. «Открыть в графе ComfyUI» — в меню **Настройки**. Там же раздел **Модели и загрузки**: рекомендованные файлы Krea 2, обеих LoRA Krea 2 Edit V2 и Qwen Image 2.1, со статусом и ссылкой. Он ничего не требует.

![Модели и загрузки](docs/settings-models.png)
- Верхняя панель в два ряда: меню и индикатор GPU/VRAM, ниже вкладки и пресет. Подробности GPU — во всплывающей подсказке. **Свернуть в ноду** остаётся в первом ряду.
- У слоёв есть видимость, замок, непрозрачность, режим наложения, дубль, удаление и перетаскивание порядка. Отмена и повтор хранят 20 шагов.
- Референс берётся из файла или с активного слоя. Заголовок панели говорит, для кого кадр: «для LLM-промта» или «для модели».
- Галерея пишет PNG в `output/zeroimagestudio/gallery` с промтом, сидом, моделью и LoRA. Рядом вкладка **Ассеты**: исходники импорта и референсы, по хешу содержимого один раз, в `user/zeroimagestudio/assets`. Плитки квадратные, в той же сетке, что генерации. На плитке метка «Холст» или «Реф» (подсказка «Референс»); размер и дата только во всплывающей подсказке. При наведении внизу плитки, на тёмном градиенте, три иконки по центру: открыть на холсте, добавить как референс, удалить. Те же три приёма — в меню по правому клику. У кадра генерации при наведении тот же ряд: применить заново, взять сид, взять LoRA. Плитку можно перетащить на холст или в референсы. Переключатель **Все** / **Этот проект** общий для генераций и ассетов (старые кадры без проекта видны только в общем списке). **Применить заново** подставляет настройки и не запускает задачу.
- **Файл → Сохранить** (Ctrl+S) кладёт проект в `user/zeroimagestudio/projects`. **Сохранить как…** спрашивает имя и скачивает zip. **Экспорт PNG** отдаёт сведённый холст. Недавние проекты живут в этом браузере.
- Пресет генерации хранит модель, LoRA, сэмплер и область, но не пиксели холста. Пресеты промта оборачивают текст только в момент постановки в очередь.
- Стек LoRA показывает только добавленные: сила, вкл/выкл, удаление, триггеры. LoRA режима Krea 2 Edit стоит первой и помечена «системная». **+ Добавить LoRA** открывает папки `models/loras` с крошками и поиском. Превью Civitai видно, если карточка уже запрашивалась. Вкладка **LoRA** остаётся полным каталогом. **Civitai info** считает хеш и читает публичный API. Триггеры можно вставить в начало, в конец или не вставлять.
- Кнопки LLM зовут OpenAI-совместимый `/chat/completions`: улучшить, дописать или описать холст. «Описать изображение» и «Улучшить» прикладывают выбранные референсы (если ни один не выбран — все, до трёх) как картинки. «Описать» ещё и сведённый холст.

Каждый запуск — обычный `/prompt` ComfyUI. Повторное нажатие во время счёта вызывает `/interrupt`.

## Своя модель

Добавьте объект в `hints/models.json`. Поле `pipelines` — список режимов, где модель видна: `create`, `edit` или оба. `tags` может быть объектом с ключами режимов. Для правки `edit_method`: `inpaint`, `krea2_edit`, `qwen_image_21` или `qwen_image`. В `defaults` — имена файлов. `sampler` и `output` необязательны. Сборщики графа из-за этого менять не нужно.

## Разработка

```bash
python -m unittest discover -s tests
node --test tests/test_generation_size.mjs
```

Тесты проверяют сборку промта, API-графы обоих пайплайнов, вклейку и общий текст размера генерации. Torch и запущенный ComfyUI не нужны.

## Как помочь

Issues и pull request принимаются.

- Пайплайны остаются общими. Новая модель — это подсказка и пресет, а не новый код, если для неё не нужна нода, которой нет в ядре ComfyUI.
- Не добавляйте зависимость от другого пака нод. Если код включается в репозиторий, сохраните его лицензию и допишите атрибуцию в `NOTICE`.
- Строки интерфейса — на русском.
- Не коммитьте ключи API, веса моделей и локальные пути машины. Настройки живут в каталоге пользователя ComfyUI.
